## 2024-05-20 - Missing noopener noreferrer on target="_blank" links\n**Vulnerability:** External links with `target="_blank"` in the Leptos frontend did not include `rel="noopener noreferrer"`.\n**Learning:** In Leptos/Rust web applications, raw HTML links still suffer from standard web vulnerabilities like reverse tabnabbing and referrer leakage if not properly secured.\n**Prevention:** Always include `rel="noopener noreferrer"` when adding external links with `target="_blank"`.
